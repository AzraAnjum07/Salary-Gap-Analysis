# Synthetic PLFS-style test data

`synthetic_plfs_test.csv` contains 6,000 entirely artificial worker-like rows created only to exercise the dashboard upload, EDA, GAM, graph explanations, and conclusions.

Columns: `gender`, `age`, `formal_education_years`, `employment_status`, `industry`, `occupation`, and `earnings_rupees`. The gender column uses `Male` and `Female`; earnings are illustrative rupee amounts. The file includes overlapping earnings and variation within both groups, plus intentionally simple associations for testing chart updates.

This is not PLFS data, does not represent India's workforce, and must not be used to draw conclusions about India's actual earnings gap or any company/workforce.
